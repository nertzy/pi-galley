# Security Policy

## Supported versions

Only the latest published version receives security fixes.

## Reporting a vulnerability

Report vulnerabilities privately through [GitHub's security advisory form](https://github.com/nertzy/pi-galley/security/advisories/new). Include the affected version, impact, and a minimal reproduction when possible.

Please do not open a public issue for an undisclosed vulnerability. Acknowledgment and follow-up will happen in the private advisory.
